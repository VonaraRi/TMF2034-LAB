# TMF2034 Database Concept and Analysis — Lab Resources

Welcome to the official lab repository for **TMF2034: Database Concept and Analysis**. This repository contains all code samples, database scripts, and practical exercise materials used throughout our laboratory sessions.

---

## 📌 Overview

This lab platform is designed to guide students through the fundamentals of database design, management, and web-based application development. You will get hands-on experience building dynamic web applications powered by relational databases and containerized development environments.

---

## 🛠️ Tech Stack & Software Tools

During these lab sessions, we will be using the following tools and technologies:

| Tool / Technology | Purpose |
| :--- | :--- |
| **MySQL** | Relational Database Management System (RDBMS) for storing and querying data. |
| **PHP** | Server-side scripting language to connect web pages with the database. |
| **phpMyAdmin** | Web-based graphical user interface to manage MySQL databases easily. |
| **HTML5 & CSS3** | Frontend technologies for structuring and styling user interfaces. |
| **Docker & Docker Compose** | Containerization platform to ensure consistent development environments across all devices. |
